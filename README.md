# VPN 日志分析工具

一个功能强大的 VPN 日志分析工具，提供直观、高效的 VPN 日志分析功能，帮助您了解 VPN 连接情况、使用趋势和数据统计。

## 项目结构

```
├── 2502/ - 2603/  # 各月份VPN日志文件（按年月命名）
├── ErrorFiles/    # 错误页面文件
├── analysis/      # 分析结果JSON文件
├── README.md      # 项目说明文件
├── generate-analysis.js  # 分析数据生成脚本
├── index.html     # 主页面
└── server.js      # 服务器脚本
```

## 功能特点

- **多种分析模式**：本地分析、服务器分析
- **灵活的时间范围选择**：单月、全年、多月选择、日期范围、自定义日期、全部日志
- **丰富的统计数据**：总连接次数、唯一IP数量、总传输数据、平均连接时长
- **直观的图表展示**：VPN协议分布、连接时段分布、每日连接数与数据使用量
- **详细的IP连接统计**：IP地址列表、连接次数、总时长、传输数据、常用VPN协议、详细连接记录
- **其他功能**：深色模式、缓存机制、搜索功能、排序功能、分页功能

## 如何使用

1. **访问主页面**：打开 `index.html` 文件或部署到服务器后访问相应URL
2. **选择分析模式**：在"分析模式"下拉菜单中选择"本地分析"或"服务器分析"
3. **选择时间范围**：根据需要选择合适的时间范围类型和具体的时间范围
4. **点击分析按钮**：点击"分析日志"按钮开始分析
5. **查看分析结果**：分析完成后，查看统计概览、图表和IP连接统计
6. **查看详细信息**：点击IP地址对应的"详情"按钮查看具体的连接记录
7. **调整图表类型**：在图表模态框中可以切换图表类型（柱状图/折线图）

## 本地启动

安装 Node.js 后，在项目目录运行：

```powershell
node server.js
```

然后访问 http://127.0.0.1:8080。默认只允许本机访问；如需更换端口，可在 PowerShell 中先运行 `$env:PORT=8081`，再启动服务器。`u.php` 需要 PHP 运行环境，Node 静态服务器不会执行 PHP。

## SoftEther 日志自动同步

运行 `copy-softether-logs.ps1` 会将服务器日志按月份复制到对应目录。脚本使用 `%LOCALAPPDATA%\SoftEtherLogSync\hash-cache.json` 缓存文件哈希；仅在日志被复制或覆盖时才运行分析。分析结果依赖全量日志，分析器仍会更新月度、年度和全量汇总。提交时日志和 `analysis/` 生成结果会一起暂存，并在推送前执行 rebase；Git 提交身份使用 `LogBot <logbot@local>`。

## 技术栈

- **前端**：HTML, Tailwind CSS, Chart.js, JavaScript
- **数据处理**：JavaScript (generate-analysis.js)

## 数据存储

- **原始日志文件**：存储在按年月命名的目录中（如 `2502/`、`2603/` 等）
- **分析结果**：存储在 `analysis/` 目录中，以JSON格式保存

## 注意事项

- 日志文件格式需要符合特定的格式要求，以便正确解析
- 分析大量日志文件可能需要较长时间，请耐心等待
- 缓存机制会自动清理48小时前的缓存数据
